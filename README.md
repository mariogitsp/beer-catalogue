# Agentic Beer Scoring Project

This project aims to create a beer discovery and review experience. It consists of a React frontend and a Node.js backend.

## Setup Instructions

### Backend
1. Navigate to the `backend` directory:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the backend server:
   ```bash
   node server.js
   ```

### Frontend
1. Navigate to the `frontend` directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the frontend development server:
   ```bash
   npm start
   ```

## Project Structure

- `backend/`: Contains the Node.js backend application.
- `frontend/`: Contains the React frontend application.
- `AGENTS.md`: Project guidelines and context for the agent.
- `.gitignore`: Specifies intentionally untracked files to ignore.
